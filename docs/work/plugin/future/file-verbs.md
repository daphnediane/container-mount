# Remaining file verbs

- **Issue:** [#24]
- **Milestone:** none (future)

The reserved verbs: `mv`, `rm`, `mkdir`, `rmdir`, `ln`, `touch`,
`chmod`, `chown`, `xattr` (macOS `xattr`-style; SELinux labels through
it, no `chcon`), `du`, `df`, `find`, `sync`, `export`/`import`, `edit`,
`inspect`, `prune`, `snapshot` (tied to [#21]), `events` ([#8]).
